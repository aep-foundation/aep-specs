# AEP IETF Governance Support

This directory contains non-normative governance support for the AEP
Internet-Draft set.

- `extension-registration.md`: extension and grant-type registration guidance
  before formal IANA registries are established.

The registration guidance also covers repository-local Claim Name
registrations until the Claims draft's requested IANA registry exists.

Repository-level governance lives in `../../GOVERNANCE.md`.
