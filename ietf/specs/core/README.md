# Core Drafts

Current core drafts:

| ---------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `draft-kavian-agent-enrollment-protocol-04.md`       | Core commands, HTTP binding, authentication, errors, registries, security, privacy.   |
| `draft-kavian-aep-claims-01.md`                      | Person and contact claim names with forward-compatible value shapes.                  |
